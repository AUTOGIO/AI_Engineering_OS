# AI Engineering OS

Personal engineering knowledge layer: constitution, schemas, and reusable notes — not a runnable app.

Vision docs (especially the constitution) may describe a future Engineering OS; **current scope is knowledge artifacts only** (Markdown + YAML contracts). No install, server, agents, or automation required yet.

**How to use:** open `AI_Engineering_OS.code-workspace` in Cursor/VS Code (or open this folder). Edit docs and schemas.

**Where things live**

- `config/engineering_kernel/` — kernel schemas and manifest
- `docs/` — constitution and guides (`docs/prompts/` for AI prompts)
- `scripts/` — helper scripts (when added)
- `archive/` — old empty scaffold folders kept for reference
- `AGENTS.md` — folder layout rules for humans and AI agents
