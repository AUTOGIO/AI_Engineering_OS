# Mission

The AI Engineering OS exists to transform engineering knowledge into reusable, composable and continuously evolving assets.

Every project contributes knowledge.

Every future project consumes knowledge.

# Canonical Objects

The Operating System recognizes only these first-class objects:

Project — `PROJECT_SCHEMA.yaml` (v0.1)

Knowledge Unit — `KNOWLEDGE_SCHEMA.yaml` (v0.1)

Pattern — `PATTERN_SCHEMA.yaml` (v0.1)

Agent — `AGENT_SCHEMA.yaml` (v0.1)

Workflow — `WORKFLOW_SCHEMA.yaml` (v0.1)

Context — `CONTEXT_SCHEMA.yaml` (v0.1)

Reasoning Session — deferred (no schema yet)

Architecture — deferred (no schema yet)

Decision — deferred (no schema yet)

Trace — deferred (no schema yet)

Report — deferred (no schema yet)

Prompt — deferred (no schema yet)

Memory — deferred (no schema yet)

Everything else is derived.

Schema files live in this directory. See `README.md` for format decision and deferred tooling.
